# NURMAN

**Модульная система управления торговлей на Laravel 12**

---

## 📋 Описание

NURMAN — это современная ERP/POS система для управления розничной торговлей с модульной архитектурой.

### 👥 Роли пользователей:

| Роль | Уровень | Доступ |
|------|---------|--------|
| 👑 **Owner** | 100 | Полный доступ ко всем функциям, финансы, отчёты |
| 🔧 **Admin** | 80 | Управление товарами, продажами, клиентами (без себестоимости) |
| 🛒 **Seller** | 50 | POS-терминал, оформление продаж |
| 📦 **Warehouse** | 20 | Склад, приёмка, инвентаризация, QR-коды |
| 👤 **Client** | 10 | Профиль покупателя, история покупок, бонусы |

---

## 🚀 Возможности

### ✅ Владелец (Owner)
- Дашборд с полной аналитикой
- Финансы (выручка, прибыль, маржинальность)
- Управление сотрудниками
- Отчёты и аналитика
- Журнал действий (Activity Logs)

### ✅ Администратор (Admin)
- Управление товарами (CRUD)
- Управление продажами и возвратами
- CRM (клиенты, купоны)
- Магазины и продавцы
- Отчёты (продажи, товары, остатки)
- QR-сканер и генерация QR-кодов

### ✅ Продавец (Seller)
- POS-терминал
- Оформление продаж
- Работа с клиентами
- Смены
- История продаж

### ✅ Кладовщик (Warehouse)
- Приёмка товара
- Остатки и инвентаризация
- QR-коды
- Перемещение между складами
- Списание товара

### ✅ Клиент (Client)
- Личный кабинет
- История покупок
- Бонусные купоны
- QR-карта лояльности

## 📦 Установка

### Требования:
- PHP >= 8.2
- Composer
- Node.js >= 18
- MySQL >= 8.0

### Шаги установки:

```bash
# 1. Клонирование репозитория
git clone https://github.com/marattop/nurman.git
cd nurman

# 2. Установка зависимостей
composer install
npm install

# 3. Настройка окружения
cp .env.example .env
php artisan key:generate

# 4. Настройка БД (отредактируйте .env)
# DB_DATABASE=nurman
# DB_USERNAME=root
# DB_PASSWORD=ваш_пароль

# 5. Миграция БД
php artisan migrate

# 6. Создание symlink для storage
php artisan storage:link

# 7. Сборка фронтенда
npm run build

# 8. Запуск (опционально)
php artisan serve
```
